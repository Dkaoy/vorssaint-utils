# Hosts 配置

在功能中心的「工具」分组安装后，从设置侧栏或命令栏搜索 `hosts` 打开。

## 使用

点击页面顶部的「查看当前 Hosts」可只读预览系统文件。支持在「完整内容」「原有内容」「Vorssaint 配置」之间切换，可选择复制文本，并用「重新读取」获取最新磁盘内容。预览使用紧凑工具栏，右上角可重新读取或关闭；行数与分区切换放在同一行，正文显示行号并支持横向和纵向滚动。注释显示灰色、IP 地址显示蓝色、域名使用正文色，Vorssaint 配置块边界显示紫色；同行注释同样区分。无需管理员授权，不会保存配置或改动 hosts；没有本工具配置时也可查看。标记不完整时仍显示完整原文并提示，分区视图暂不可用。

1. 新增配置，填写名称、说明和映射。每条包含一个 IPv4 / IPv6 地址和一个或多个空格分隔的域名。
2. 保存新配置不会改动系统文件。开启配置的开关，检查变更预览，再点击「授权并应用」。
3. 多份配置可以同时启用。重复域名会在应用前提示；同一主机的 IPv4 / IPv6 双栈映射也会提示，由你决定是否保留。
4. 编辑启用中的配置、停用或删除启用配置，都需要经过预览与系统管理员授权。
5. 如解析结果未及时变化，可手动「刷新 DNS」。浏览器或其他应用可能还有自己的缓存。

## 文件与保护

- 系统目标固定为 `/private/etc/hosts`（即 `/etc/hosts`），仅维护带 UUID 的 `Vorssaint Hosts` 标记块；名称和说明保存在本机配置中，不写入 hosts。
- 标记区以外的内容按字节保留，包括注释、空行、CRLF 和文件末尾是否换行。没有末尾换行时，新增的分隔换行也由标记区管理。
- 未知配置块、不完整标记、外部修改过的映射会阻止写入。请先检查外部改动或在原安装中停用配置。
- 每次授权前和实际写入前核对文件 SHA-256。写入使用 root 所有的固定目录锁和同目录临时文件，保留权限后原子替换。不会添加免密 sudo 或常驻后台助手。
- 文件上限为 64 KiB；配置最多 100 份，每份最多 500 条映射，每条最多 32 个域名。域名不支持通配符、URL、行内注释或 Unicode（国际化域名请使用 Punycode）。
- 原始备份 `hosts.backup` 和配置 `profiles.json` 位于 `~/Library/Application Support/<应用 bundle id>/Hosts/`，仅当前用户可读写。备份仅保留最近一次写入前的版本，不上传。
- 「恢复上次配置」恢复最近一次写入前的配置及启用状态，仍需预览和授权。当前外部原文保留，不会直接用整个备份覆盖系统文件。
- 关闭应用、退出登录或卸载工具不会撤销映射。请在卸载前使用「停用全部」。
- 若写入进程被强制终止，可能留下 `/private/etc/.vorssaint-hosts.lock`。确认没有正在运行的写入后，由管理员移除残留锁再重试；工具不会擅自删除一个可能仍在使用的锁。

## 验证

`zsh Tools/test-fork-features.sh hosts` 运行 Hosts 独立测试，覆盖原文保留、标记块增删、输入与冲突校验、写入并发保护、符号链接拒绝和权限保留。写入测试只操作临时文件，不使用真实 hosts 或管理员授权。
