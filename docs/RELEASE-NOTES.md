## Vorssaint 3.4.5 · Dkaoy fork

本次更新为 Dynamic Island（灵动岛）增加自选背景色。此前已在本机安装 3.4.5-beta.1 测试，现发布正式版本。

### 新增

- 在「设置 → Dynamic Island → 布局 → 背景颜色」开启「使用自选背景色」。
- 提供经典黑、深海蓝、松针绿、暮光紫、暖棕色五组预设，也可通过系统取色器自定义颜色。
- 实际岛、快捷按钮和布局／内容预览同步变化，设置自动保存并可随设置备份导出。
- 支持恢复默认。自选色使用纯色背景；关闭后恢复之前的透明或玻璃选项。
- 浅色会自动调暗，保证现有白色文字可读；实体摄像头刘海仍为黑色。

继续保留 Apple / AI API / Codex CLI 翻译、Hosts 配置与只读预览，以及新版上游其他功能。

### 安装与更新

支持 Apple Silicon（arm64），macOS 14 或更新系统。本安装包采用 ad-hoc 签名，**未经 Apple 公证**。打开 DMG，将 Vorssaint 拖入「应用程序」；也可解压 ZIP 后安装。

若 macOS 阻止打开，请在「系统设置 → 隐私与安全性」中确认来源后选择「仍要打开」。更换二进制后可能需要重新授予辅助功能或录屏权限。受保护的风扇控制助手仍保留可信签名校验，在本构建中不可用。

更新源为 Dkaoy/vorssaint-utils 的 GitHub Releases，仅提示手动下载和安装，不运行自动安装程序。
