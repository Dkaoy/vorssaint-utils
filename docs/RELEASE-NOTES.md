## Vorssaint 3.4.6 · Dkaoy fork

本次更新改善 Hosts 只读预览，让配置内容更容易查看。

### 改进

- 将大标题、说明、重复状态栏和底部按钮收紧为两行工具栏，扩大正文区域。
- 合并分区切换与行数统计，缩小行间距，窗口扩大到 860 × 620；常规预览可显示约 27 行内容。
- 增加语法配色：注释灰色、IP 地址蓝色、域名使用正文色，Vorssaint 配置块边界紫色；同行注释也会区分。
- 适配浅色与深色外观，保留文本选择复制、行号、分区切换、重新读取及异常标记提示。

继续保留灵动岛自选背景色、Apple / AI API / Codex CLI 翻译、Hosts 配置及其他现有功能。预览仅负责展示，不修改系统 hosts。

### 安装与更新

支持 Apple Silicon（arm64），macOS 14 或更新系统。本安装包采用 ad-hoc 签名，**未经 Apple 公证**。打开 DMG，将 Vorssaint 拖入「应用程序」；也可解压 ZIP 后安装。

若 macOS 阻止打开，请在「系统设置 → 隐私与安全性」中确认来源后选择「仍要打开」。更换二进制后可能需要重新授予辅助功能或录屏权限。受保护的风扇控制助手仍保留可信签名校验，在本构建中不可用。

更新源为 Dkaoy/vorssaint-utils 的 GitHub Releases，仅提示手动下载和安装，不运行自动安装程序。

### 验证

发布前翻译 80 项、Hosts 97 项、背景颜色 148 项专项检查通过，合计 325 项。预览组件编译、中文浅色／英文深色渲染及文本保留检查通过。

正式 arm64 应用构建、ad-hoc 签名校验、临时隔离副本自检及安装包校验通过。本次未重新运行所有历史套件；验证没有修改真实系统 hosts，也没有替换本机已安装应用。
